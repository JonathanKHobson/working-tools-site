About the builder

Tools should make the work easier to inspect.

I’m Jonathan Kyle Hobson, a UX researcher, product strategist, teacher, game master, and AI-tool builder. I build narrow tools around repeated work: reviewing evidence, shaping a draft, checking an interface, preparing a table, or closing a handoff.

Working principles

The boundary is part of the design.

A useful AI tool does not need to pretend it can do everything. It needs a clear job, known inputs, visible limits, and a result someone can check.

Start with the task

The library is organized around what a person is doing, beyond which product name they already happen to know.

Show the evidence

Each released package has a public home for its source, installation steps, examples, and tested limits.

Keep judgment human

The tools can structure, surface, compare, and question. The person using them remains responsible for the choice.

Background

Research, design, storytelling, and emerging technology.

My work crosses UX research, product strategy, facilitation, teaching, games, and AI-assisted workflows. That mix matters here: these are working materials shaped by actual constraints, not a claim that one method fits every setting.
