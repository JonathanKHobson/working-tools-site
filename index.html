03 / Boundary

Every listing has somewhere useful to go.

Working Tools is one organized collection, with studios, templates, and toolkits that help you take a task from first question to usable result. Each product page shows exact downloads, version history, and guidance for installing or upgrading. GitHub keeps the source and original release files. Looking for an earlier resource? Visit the legacy library.

05 / Builder

Built from real work. Kept small on purpose.

I’m Jonathan Kyle Hobson, a UX researcher, product strategist, teacher, game master, and AI-tool builder. I make these tools when a repeated task needs a clearer boundary, a better handoff, or proof that the work actually finished.

The library will grow. Each tool should help you do something useful, explain its limits, and produce work you can review.
